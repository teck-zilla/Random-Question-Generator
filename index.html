A lightweight serverless API that returns a random question on request. Built with AWS Lambda and API Gateway, and provisioned with Terraform.

01 / Overview

Small project, real cloud workflow.

The project demonstrates a simple serverless setup without a database: an API Gateway endpoint invokes a Lambda function, which selects and returns a question.

Fully serverless

No servers or infrastructure to manage for the application runtime.

Fast + cheap

A deliberately small architecture designed for a simple use case.

Easy to extend

The PDF identifies DynamoDB, a React frontend and Cognito as future additions.

03 / Implementation

Infrastructure and function code.

The Lambda contains a small list of questions and uses Python's random selection to choose one.

lambda/function.py
import json
import random

questions = [
  "What inspires you the most?",
  "If you could travel anywhere, where would you go?",
  "What is your favorite song right now?",
  "What does success mean to you?",
  "What’s a skill you want to learn?"
]

def lambda_handler(event, context):
    question = random.choice(questions)
    return {
      "statusCode": 200,
      "body": json.dumps({"question": question})
    }

05 / Lessons learned

Debugging the API deployment.

One issue documented in the project was a “Missing Authentication Token” error caused by API Gateway not being able to invoke the Lambda. The project addressed this by adding the appropriate source_arn to the Lambda permission and by adding a Terraform deployment trigger so changes to methods or integrations force a new deployment.

The notes also describe targeting the API Gateway stage and deployment for destruction when an old deployment was still interfering with updated changes.
